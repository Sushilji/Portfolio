# Sushil Kumar Portfolio

A static portfolio for Sushil Kumar, featuring selected projects from GitHub and direct contact links.

## Open locally

Open `index.html` in a browser. The page has no build step or dependency installation.

## Publish on GitHub Pages

1. Push the repository to GitHub.
2. Open **Settings > Pages** in the `Sushilji/Portfolio` repository.
3. Under **Build and deployment**, select **GitHub Actions**.
4. Push to `main` to deploy the site.

The portfolio will be available at:
https://sushilji.github.io/Portfolio/
